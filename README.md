# frontier-ai-tradeoffs

Agent skill encoding principles of frontier AI progress drawn from OpenAI engineering practice.

## What this skill does

- Frames frontier AI development as multi-dimensional trade-off management rather than linear capability growth
- Emphasizes expanding the Pareto frontier (quality ↔ speed, capability ↔ safety, cost ↔ performance)
- Treats cost reduction and latency/inference improvements as strategic enablers of the next capability leap
- Encourages reverse-engineering from real user/product constraints

## Usage

Drop `SKILL.md` into an agent skills directory (e.g. `.grok/skills/frontier-ai-tradeoffs/`).

The skill activates on discussions of frontier model development, post-training, scaling, trade-offs, Pareto boundaries, cost efficiency, and related topics.

## Source

Distilled from public reflections of a new-grad engineer after one year at OpenAI.
